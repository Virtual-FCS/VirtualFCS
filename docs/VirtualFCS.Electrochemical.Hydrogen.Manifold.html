VirtualFCS.Electrochemical.Hydrogen.Manifold

Fuel cell manifold

Model Description and References

This is a specialisation of MixingVolume that implements chemical reactions.
The rate of reaction [mol/s] is provided by the r input; this modifies the holdup of each species depending on their stoichiometric coefficient nu and molar masses MMX.

Note that there is no enforcement that the stoichiometric coefficients are balanced: if the reaction is not balanced, the Manifold must be either:
  • Set to zero reaction rate, or
  • Have the heatPort deactivated so that temperature is set to parameter T, or
  • Be connected through the heatPort to another Manifold with the same reaction rate and whose stoichiometry balances the first one.
The last case is the one implemented e.g. in fuel cells between anode and cathode.

An unbalanced reaction occuring in isolation is not a physically meaningful model, and will produce nonsensical results, typically with extremely high or low temperatures, often leading to numerical crashes.
