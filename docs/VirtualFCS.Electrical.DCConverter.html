VirtualFCS.Electrical.DCConverter

DC controlled single phase DC/AC converter

Model Description and References

This is an ideal DC/DC converter with internal resistances.

Input voltage is set programmatically by parameter vDCref, but that does not do what you would expect since it does not account for the effect of the internal resistor; input voltage will be different from the reference one.

Input voltage is not set and constant through a simulation, though, since if current changes so does the internal resistance loss on the input side.

The output power sensor does not include the loss from resistor1, making output power a bit lower than measured.
