VirtualFCS.Vehicles.DriveCycle

Model Description and References

The DriveCycle block is designed to read a speed profile from a Matlab/.txt file. 

The block enables the user to select from standard testing drive cycles including WLTC Class 1-3 and NEDC. The drive cycles are provided as .mat files in the library directory containing the block.

The selected CombiTimeTable uses ContinuousDerivative interpolation, periodic extrapolation, and time events at discontinuities. Its first column of output is exposed as velocity y in km/h. The profile_file and profile_variable helper functions resolve the standard library cycles or the custom file and table names.
