VirtualFCS.Electrochemical.Hydrogen.ECM.OhmicNafion

Model Description and References

This is a base class for units calculating the Ohmic loss in a fuel cell stack.

It only implements the number of cells, which is imported from the outer scope.

Governing Equations

R_ohm_ele = t_ele*rho_ele/A_cell;

E_ohm_A = R_ohm_ele*i;

E_ohm_C = E_ohm_A;

sigma_mem = (0.005139*lambda - 0.00326)*exp(1268*((1/303) - (1/max(T_stack, 293.14))));

R_ohm_mem = t_mem/(sigma_mem);

E_ohm_mem = R_ohm_mem*i;

E_ohm = E_ohm_A + E_ohm_C + E_ohm_mem;

v = E_ohm;
