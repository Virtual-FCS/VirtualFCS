VirtualFCS.Media.PartialCondensingMixture.gasMolarFractions

Given a generalised molar vaporisation ratio β, molar fractions Xmol and inverted equilibrium constants iK, the function returns the corresponding molar fractions in the gas phase.
Note that, if β≥1 (i.e. only gas), the gas concentrations are simply the overall ones.

The case of β≤0 is a bit more thorny since no gas phase exist, and the gas fractions do not have a physical meaning, but must be defined nevertheless to ensure continuity of variables.
The main problem occurs when β=0, since the denominator of the main formula would collapse to zero for all incondensables, which already have iK=0 by definition of incondensables. Of course there cannot be incondensables present if β=0, but 0/0 would still produce an error.
