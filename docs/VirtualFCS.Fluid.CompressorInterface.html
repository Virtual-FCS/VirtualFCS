VirtualFCS.Fluid.CompressorInterface

Model Description and References

This partial class defines the interfaces of a mechanically-driven compressor, combining several standard Modelica classes.

Mechanical work is delivered to the compressor via a shaft, which connects flange_a and flange_b internally; this allows connecting a motor on one flange and a turbine on the other.

Heat can be set in different ways depending on the value of heatport: the exact mechanisms are set in child classes.
