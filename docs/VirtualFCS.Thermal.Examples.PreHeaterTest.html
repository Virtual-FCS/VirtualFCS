VirtualFCS.Thermal.Examples.PreHeaterTest

Simple model to test the PreHeater model

Model Description and References

This test connects the pre-heater between fluid boundaries at 506625 Pa inlet and 476228 Pa outlet. The pipe length is 100 m and the water medium and 25 V nominal battery use model defaults.

No explicit flow, fluid temperature, or time-varying excitation is prescribed. The experiment runs from 0 to 600 s with 0.5 s output intervals.
