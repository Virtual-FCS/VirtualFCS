Introduction

Since v2.0.0, VirtualFCS has been substantially reorganized and extended. The update adds new media and chemical-process models, makes core components more modular, and expands the electrical, fluid, electrochemical, and vehicle-modelling options.

Highlights

  • Model architecture: Increased use of standard Modelica replaceable packages and components, allowing media and submodels to be redeclared in derived models. Fuel-cell models now share a common interface for fluid, electrical, and thermal connections. Dependencies from Buildings and AixLib libraries have been removed.
  • Fuel-cell equivalent-circuit model: The electrical response is assembled from replaceable open-circuit-voltage, ohmic-resistance, activation-loss, and mass-transport-loss elements. Alternative voltage-source and loss models can be selected without rewriting the overall fuel-cell model.
  • Power electronics: Refactored and expanded the converter structure around reusable abstract bases. The library now includes averaged and switching converter approaches, boost and commutator variants, a step-up/down chopper, and DC/DC converter models, with PWM and component test examples.
  • Media: Added a dedicated media package covering moist air and hydrogen, condensing mixtures, and media for PEM electrolysis and cracked ammonia. The package features a general framework for mixtures of multiple condensing species based on the Rachford-Rice equation.
  • Fluid and balance of plant: Updated compressor models and added map-based compressor performance. Developed dynamic membrane humidification and added or revised supporting components including separators, PSA models, pumps, valves, and heat exchangers.
  • Batteries, vehicles, and controls: Updated battery models and parameters, vehicle and powertrain examples, and energy-management controls, including an ECMS variant. System-level component choices and subsystem models are more configurable.
  • Electrolysers and ammonia processing: Added initial electrolyser interfaces and a PEM electrolyser model. Added static and dynamic ammonia-cracker models, with examples coupling ammonia processing, hydrogen separation, and fuel-cell systems.
  • Documentation and tests: Expanded and standardized model documentation, added examples, and moved component/system tests into the packages they exercise. Automated CI testing has been added.
  • Package structure: Package structure has changed. In particular, the former ComponentTesting package has been removed as tests were moved into package-specific Examples packages. XInTheLoop was removed, with user-interaction utilities placed under Utilities. Existing models that reference old paths may need updated imports or instance paths.

Deprecated Features

  • Library is tested with OpenModelica v1.24 to v1.27 but is expected to work down to OpenModelica v1.20.
  • Library uses MSL 4.1.0.
  • Library uses Modelica_DeviceDriver 2.1.0.
  • Library may work on Dymola and other platforms, but they are not tested.

Support and Feedback
