VirtualFCS.Control.ECMS.efficiencyFC

Model Description and References

Empirical fuel-cell-system efficiency approximation used by the ECMS cost function. A sixth-order polynomial in fuel-cell power (W) is evaluated and limited from below to 0.1. There is no upper efficiency clamp in this implementation; the fit should only be used over its calibrated operating range.

Note: Must rethink this approach.
