VirtualFCS.Electrochemical.Hydrogen.ECM.OhmicResistance

Ohmic resistance to proton flow through MEA

Model Description and References

This resistor implements a variable ohmic resistance as typically encountered in PEM fuel cells.

A reference value is usually provided by the manufacturer for a reference temperature, which is then corrected for temperature and relative humidity.

  • From Yadav and Fedkiw, temperature dependence of conductivity follows an Arrhenius relationship;
  • From Zhang et al. conductivity is closely linear with relative humidity, meaning the actual resistance value is obtained dividing by φ.

Relative humidity is provided with the custom input connector; temperature with the conditional heat port.

The default value for resistance Rref is taken from Yadav and Fedkiw's typical value for Nafion 117 at 330 K, 0.1 S/cm. A thickness of 0.2 mm and and area of 100 cm2 are then assumed, resulting in 2 mΩ.

Governing Equations

i_area = i/A_el;

R = R_ref*exp(1/T_stack - 1/T_ref) / phi;

v = N_cells * R * i_area;
