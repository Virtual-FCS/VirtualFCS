VirtualFCS.Electrical.ChopperStepUpDown

Step up/down chopper

Model Description and References

This is a conventional step up/down chopper (buck-boost converter) model. It consists of a transistor, and inductance and free wheeling diode.

Class made after the examples in Modelica.Electrical.PowerConverters.DCDC.

Note that a plain buck-boost would invert voltage, and not be consistent with the output pin interface; therefore there is an internal inversion.

Governing Equations

if not useHeatPort then LossPower = diode.LossPower + transistor.LossPower;
