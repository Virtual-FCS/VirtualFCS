VirtualFCS.Electrical.AveragedBoostConverter

Model Description and References

An averaged model of a boost DC-DC converter with coupled inductors.
The usage of averaged units allows a far quicker simulation than with the rigorous model, but also loses track of details: the model is not reliable outside of continuous current mode (CCM).
