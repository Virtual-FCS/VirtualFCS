VirtualFCS.Fluid.SimplePump

A simple pump for liquids or gases with small pressure difference

Model Description and References

A bare-bones model for a pump. The input u sets the mass flow directly. The pump must be connected to a DC power supply providing voltage.

The model has one parameter, efficiency η, which defaults to 100%.

The pump has no holdup and is meant to be directional, with the higher pressure to be found at port_b.

Note: this model can be used only with either incompressible media (liquids) or with gases with minimal pressure drop (e.g. fans and blowers). To faithfully model significant pressure drops in gas phase, use a Compressor.

Governing Equations

power = (pin_p.v - pin_n.v)*(pin_p.i);

port_a.m_flow + port_b.m_flow = 0 "No mass holdup";

port_a.h_outflow = inStream(port_b.h_outflow) + head*g_n;

port_b.h_outflow = inStream(port_a.h_outflow) + head*g_n;

LossPower = 0;

pin_p.i + pin_n.i = 0;

head = (port_b.p - port_a.p)/ Medium.density(Medium.setState_phX(port_b.p, port_b.h_outflow, port_b.Xi_outflow)) / g_n;

eta*power = u * head * g_n;
