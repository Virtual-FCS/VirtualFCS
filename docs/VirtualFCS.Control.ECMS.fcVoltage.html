VirtualFCS.Control.ECMS.fcVoltage

Model Description and References

Estimates total fuel-cell stack voltage as the Nernst voltage minus activation, ohmic, and mass-transport losses. Stack current is divided by active area to obtain current density. Each voltage contribution is multiplied by N_FC. The activation logarithm is limited below by one, and the limiting-current logarithm denominator is bounded by a small positive current density. The ohmic term scales with R_ref, temperature, and the hydration factor phi, which must be nonzero. Temperature, active area, and reactant partial pressures must be positive.

Governing Equations

i_0 = 0.03;

R_ref = 0.15e-4;

i_limit = 16000;

alpha = 1;

i_epsilon = 1E-39*i_limit;

i_area := i/A_fc;

Nernst := N_FC*(E0 + Modelica.Constants.R*temp/(n_e*Modelica.Constants.F)*Modelica.Math.log(pressure_H2/p_ref *(pressure_O2/p_ref)^0.5) + delta_S/(n_e*Modelica.Constants.F)*(temp - T_ref));

activation := N_FC * Modelica.Constants.R * temp / (alpha * Modelica.Constants.F) * Modelica.Math.log(max(i_area/i_0,1));

ohmic := N_FC * (R_ref*Modelica.Math.exp(1/temp - 1/T_ref) / phi) * i_area;

massTransport := N_FC * Modelica.Constants.R*temp/(N*Modelica.Constants.F) * log(i_limit/max(i_limit-i_area, i_epsilon));

V := Nernst - activation - ohmic - massTransport;
