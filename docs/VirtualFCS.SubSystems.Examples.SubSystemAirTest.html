VirtualFCS.SubSystems.Examples.SubSystemAirTest

Simple model to test the compressor component

Model Description and References

This test case tests the operation of the air subsystem against a simple manifold.
Note that, if you set a reaction rate larger than zero, you must deactivate the manifold's heat port, or connect it to some constant or prescribed temperature source.
This is because the reaction makes matter "disappear" without changing the enthalpy content, and therefore the enthalpy balance will become nonsensical; this balance works only when multiple manifolds (e.g. cathode and anode) with matching stoichiometric coefficients are connected.
