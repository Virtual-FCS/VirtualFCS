2. Model description

The model regulates electric heat supplied to an ammonia-cracker bed. A bounded PI controller requests non-negative heater power up to q_max. Depending on the selected options, that request can include a feed-forward term, pass through a first-order startup filter, and be distributed across the segment heat ports according to heatWeights.

With use_cascade = false, T_meas closes the heater PI loop directly against T_out_target. With use_cascade = true, an outer PI loop compares T_meas with T_out_target and produces a bounded offset. This offset is added to T_out_target to form the bed-mean temperature set-point. The inner heater PI loop then compares that set-point with the arithmetic mean of heatPorts.T.

When useHeatFilter = true, the heater command is first filtered from an initial output of zero, then multiplied by heatWeights[i]/sum(heatWeights) for each segment. This preserves the total commanded heat flow for weights whose sum is nonzero. When useHeatFilter = false, the filter and distribution gains are absent and the full PI output is connected to every segment port; consequently, the sum of segment heat flows can be N times the controller output. In this mode heatWeights and T_heatFilter do not affect the model.

3. Governing equations and usage notes

0 <= PI_heater.y <= q_max

T_bedMean = sum(heatPorts[i].T for i in 1:N)/N

use_cascade = false: PI_heater set-point = T_out_target, measurement = T_meas

use_cascade = true:  T_bedSet = T_out_target + outerPI.y

                     outerPI: set-point = T_out_target, measurement = T_meas

                     PI_heater: set-point = T_bedSet, measurement = T_bedMean

useHeatFilter = true: Q_segment[i] = heatFilter.y*heatWeights[i]/sum(heatWeights)

useHeatFilter = false: Q_segment[i] = PI_heater.y

The feed-forward input is enabled independently of cascade mode and is combined by the LimPID block before the heater output limiter. The heat filter and heat distribution are enabled together by useHeatFilter. Ensure that N matches the heatWeights vector length when distribution is enabled, and that the weights have a nonzero sum.

4. Outputs

No signal output connectors are declared. Heat is delivered through heatPorts[N]. For monitoring, PI_heater.y is the limited heater command before optional filtering and distribution; when cascade control is enabled, outerPI.y is the bed-mean set-point offset and T_bedMean.y is the mean segment temperature.
