VirtualFCS.Electrochemical.Hydrogen.ECM.MassTransportLossElec

Model Description and References

This is a base class for units calculating the mass transport loss in a fuel cell stack.

It only implements the number of cells, which is imported from the outer scope.

Governing Equations

j = i/A_cell;

E_diff = (R*T_stack)/(2*F)*log(abs(1 - (j/i_L)));

v = E_diff;
