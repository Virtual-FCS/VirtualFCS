VirtualFCS.Fluid.ElectricCompressorInterface

Model Description and References

This is an interface for classes combining a mechanical compressor acting on a fluid flow, a DC motor, and a DC/DC converter drawing power from an external source.
The unit takes as input a mass flow set point.
The heatPort can be left disconnected to achieve adiabatic conditions, or set to a specific temperature for isothermal operation.
