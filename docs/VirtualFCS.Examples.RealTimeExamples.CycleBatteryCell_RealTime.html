VirtualFCS.Examples.RealTimeExamples.CycleBatteryCell_RealTime

Example demonstrating constant-current constant-voltage cycling of a Li-ion battery cell.

Model Description and References

This real-time example applies alternating -2.2 A and +2.2 A galvanostatic pulses to a Li-ion cell. Each pulse lasts 15 s within a 30 s period.

The cell starts at SOC = 0.01 and 298.15 K. It requires Modelica_DeviceDrivers for real-time scheduling and I/O.
