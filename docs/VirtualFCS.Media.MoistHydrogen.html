VirtualFCS.Media.MoistHydrogen

Media model for hydrogen containing water vapour

This medium is appropriate for hydrogen in presence of water, e.g. fuel-cell anode or electrolyser cathode.
It is very similar in structure to MoistAir, only it has only hydrogen as incondensable gas.
