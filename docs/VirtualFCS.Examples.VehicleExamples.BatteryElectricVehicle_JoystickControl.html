VirtualFCS.Examples.VehicleExamples.BatteryElectricVehicle_JoystickControl

Model Description and References

This example replaces a prescribed drive cycle with joystick velocity input for a Mirai-profile battery-electric vehicle. The battery starts at SOC = 0.9 with 200 Ah capacity, nominal voltage 320 V, and limits of 300 V to 360 V.

The user provides the driving excitation.
