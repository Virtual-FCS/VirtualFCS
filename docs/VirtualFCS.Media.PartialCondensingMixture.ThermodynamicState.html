Thermodynamic state variables

To keep things simple, we assume that pTX is a sufficient representation of the thermodynamic state.
Strictly speaking, it isn't, since there are corner cases like water at 0 or 100 C.
If we were to handle these cases correctly we should use h instead of T, but then we need to invert h(T), which is an onerous operation since Shomate equations are polynomials of T and would need to be solved iteratively: this it possible but numerically onerous.
It would also be possible to calculate new direct correlations T(h), but this becomes rapidly a larger job.
Since pure freezing or boiling water is an extremely rare case in the systems we study, we use the more convenient option.
