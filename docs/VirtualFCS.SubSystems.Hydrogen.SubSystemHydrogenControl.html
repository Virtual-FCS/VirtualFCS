VirtualFCS.SubSystems.Hydrogen.SubSystemHydrogenControl

Model Description and References

SubSystemHydrogenControl generates the three commands required by the hydrogen supply assembly: hydrogen feed pressure, purge-valve opening, and recirculation-blower speed.

Working principle

The stack-current input is converted to an estimated hydrogen flow using the cell count and recirculation ratio RR. A minimum-flow path prevents the commanded blower flow from reaching zero. A pressure controller uses the measured blower speed and requested flow to calculate the blower-speed command, while PurgeValveControl determines purge operation.

Interfaces

p_h2_set provides the pressure-regulator set point, purge_set controls the purge valve, and pumpSpeed_set controls the recirculation blower. The pressure target, cell count, recirculation ratio, minimum flow, and measured blower speed are inputs or parameters of the control arrangement.
