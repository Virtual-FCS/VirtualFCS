2. Model description

Alternative simplified tube-and-shell ammonia cracker with catalytic decomposition and heat transfer through the outer tube wall.

The model is intended for system-level studies.

3. Governing equations and references

The following representative equations are implemented directly. Equations inherited through extends and component connections also contribute to the complete model balance.

g_catalyst_mol_flow_NH3 = W_cat*A_r/(mf_NH3*1000/M_NH3/3600);
