VirtualFCS.Electrical.DCConverterSwitch

DC controlled single phase DC/AC converter

Model Description and References

This is a DC/DC converter with an off switch.

When the boolean input u is off, output current is set to zero, and the input circuit is opened. There should be no wind-up issues since both powers are identically zero when u is off.
