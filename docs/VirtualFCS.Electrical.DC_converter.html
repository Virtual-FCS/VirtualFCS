VirtualFCS.Electrical.DC_converter

An ideal DC-DC converter

Model Description and References

This is a model of an ideal DC-DC inverter based on a power balance achieved by an integral controller.

The setup is similar to the Modelica Standard Library's IdealDcDc, but with the key differences that:

  • This unit is output-current-controlled rather than voltage-controlled, meaning it must be connected to some kind of load in order to compile;
  • The unit does not have internal grounding in the output, so a ground has to be attached there;
  • Due to a programming bug (or feature?), setting a positive current reference will result in inverted polarity in the output. This is because the program makes power on both sides equal, but one should be entering and the other exiting.
