VirtualFCS.Electrochemical.Hydrogen.ECM.VSourceNernst

Model Description and References

This unit calculates the Nernst potential of a fuel cell based on oxygen and hydrogen partial pressures and stack temperature.
These variables are passed as outer scope declarations.

Governing Equations

v = N_cells*(E0 + R*T_stack/(n_e*F)*log(max(p_H2/p_ref, 1) *(max(p_O2/p_ref, 1))^0.5) + delta_S/(n_e*F)*(T_stack - T_ref));

p_O2Oxygen pressure
