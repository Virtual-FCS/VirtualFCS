VirtualFCS.Electrochemical.ButlerVolmer

Model Description and References

Butler-Volmer electrochemical reaction model relating activation overpotential to current density.

Governing Equations

i = i_0 * (exp(alpha*N*F*v/R/T_heatPort) - exp(-(1-alpha)*N*F*v/R/T_heatPort));

LossPower = v*i;
