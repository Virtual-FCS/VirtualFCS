User information for the VirtualFCS library

VirtualFCS is an open Modelica library for dynamic modelling of hydrogen and hybrid energy systems. It includes fuel cells, batteries, electrolysers, balance-of-plant components, vehicle powertrains, and ammonia cracking, with examples for transport and other applications.

For requirements, installation, and example models, see the project README. The source is hosted on GitHub. Contributions and issue reports are welcome through the repository's pull requests and issue tracker.
