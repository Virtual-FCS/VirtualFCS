VirtualFCS.SubSystems.Examples.SubSystemCoolingWithFuelCellTest

Model Description and References

This test couples the cooling subsystem to a 42-cell fuel cell. It uses lambda = 3, 2.5e5 Pa air pressure, 7.5e-5 kg/s air flow, 320 K stack temperature, 323.15 K coolant start temperature, and a 24 V supply.

The load resistance steps from 30 ohm to 50 ohm at 250 s.
