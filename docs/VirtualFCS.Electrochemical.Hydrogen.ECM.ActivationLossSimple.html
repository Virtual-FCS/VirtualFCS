VirtualFCS.Electrochemical.Hydrogen.ECM.ActivationLossSimple

Model Description and References

Voltage activation loss which occurs due to sluggish kinetics associated with small overpotentials, i.e low current regime. The formula used in this element is taken from Barbir's "PEM Fuel Cells - Theory and Practice", Elsevier, 2013, eq. 3-41.
It expresses the loss in Nernst potential when drawn current approaches the exchange current density i0 

Governing Equations

i_area = i/A_el;

v = N_cells * R*T_stack/(alpha*F) * log(max(i_area/i_0, 1));
