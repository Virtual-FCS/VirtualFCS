VirtualFCS.Electrochemical.Hydrogen.FuelCells.FuelCellSystem

Model Description and References

The FuelCellSystem class packages together a FuelCell object and three different subsystems to control hydrogen, air, and coolant feeds into and out of the fuel cell. A battery object provides power to the subsystems.

Governing Equations

Power_system = Power_stack-Power_BOP;

Power_stack = fuelCell.pin_n.i*(fuelCell.pin_p.v-fuelCell.pin_n.v);

Power_BOP = batterySystem.pin_n.i*(batterySystem.pin_p.v-batterySystem.pin_n.v);

eta_sys_HHV = min(Power_system/(max((fuelCell.anode_in.m_flow + fuelCell.anode_out.m_flow), 1e-10)*H2HHV)*100, eta_max);

eta_sys_LHV = min(Power_system/(max((fuelCell.anode_in.m_flow + fuelCell.anode_out.m_flow), 1e-10)*H2LHV)*100, eta_max);
