VirtualFCS.Electrochemical.Hydrogen.Electrolysers.ElectrolyserInterface

Model Description and References

This is a general interface for electrolyser classes of any technology.
Hydrogen is produced on the cathode and oxygen on the anode.
No hypothesis is made on the directionality of the flow connectors.

As several technologies such as PEM use feed water as coolant, no separate coolant loop is foreseen; child classes may implement it if required.
