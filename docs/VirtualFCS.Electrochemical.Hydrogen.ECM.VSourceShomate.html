VirtualFCS.Electrochemical.Hydrogen.ECM.VSourceShomate

Model Description and References

This unit calculates the reversible voltage of a hydrogen fuel cell as a function of temperature (either set directly with T, or through the heatPort) and partial pressures in anode and cathode.
In case of relative humidity φ below 100%, the unit automatically switches to using the ΔG0f of water vapour instead of liquid (reducing voltage); also, φ is used as an estimate of water activity, so the reversible voltage will increase with lower humidity (this effect will be weak and more than compensated for by increases ohmic resistance).

Governing Equations

H2O = if cathode_phi < 1 then Shomate.H2O_G else Shomate.H2O_L;

a_H2 = p_H2 / p_reference;

a_O2 = p_O2 / p_reference;

a_H2O = max(cathode_phi, Modelica.Constants.eps);

DeltaG0 = Shomate.gibbs_free_energy(T_stack, H2O) - Shomate.gibbs_free_energy(T_stack, Shomate.H2) - 0.5*Shomate.gibbs_free_energy(T_stack, Shomate.O2);

v = N_cell * (-DeltaG0/2/F + R*T_stack/(2*F)*log(max(a_H2 * max(a_O2,1)^0.5 / a_H2O, 1)));
