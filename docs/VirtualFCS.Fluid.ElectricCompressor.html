VirtualFCS.Fluid.ElectricCompressor

Model Description and References

This is an implementation of an electric compressor assembly. The unit contains a compressor driven by a DC motor, voltage-controlled by a converter, which is in turn manipulated by a PI controller that attempts to match the reference flow to the inlet flow.

Note that the unit has an internal controller (by default PI) that needs to be properly tuned to the problem.
Bad tuning will often show up as high-frequency oscillations in the controller output, which will slow down simulation; detune the controller gain in that case.
