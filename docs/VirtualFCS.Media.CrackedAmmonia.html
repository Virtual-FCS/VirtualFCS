VirtualFCS.Media.CrackedAmmonia

This medium represents a mix of ammonia and its cracking products, nitrogen and hydrogen. Only ammonia is condensable.
Note that thermochemical data for liquid ammonia is not available from NIST, and was calculated from data in Perry's with a Python script stored in Utilities.
