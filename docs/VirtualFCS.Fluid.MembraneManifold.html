VirtualFCS.Fluid.MembraneManifold

Manifold with a selective membrane source

Model Description and References

This component extends the VirtualFCS fuel-cell Manifold directly. It adds a signed selective membrane source to the manifold's existing mass, species, and enthalpy balances. A positive membrane_m_flow adds mass to the volume and a negative value removes it. The original manifold model is otherwise unchanged.


The inherited manifold determines port outflow states and provides the existing hydraulic resistance, fluid holdup, and conditional heat port. This component is used as the wet-side and dry-side cell volume in Humidifier, where the membrane inputs are driven by a paired MembraneTransfer instance.
