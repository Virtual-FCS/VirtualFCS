VirtualFCS.SubSystems.Cooling.SubSystemCooling

Model Description and References

SubSystemCooling circulates coolant through a fuel-cell stack and controls both stack and reservoir temperature.

Composition

The model consists of an open coolant reservoir, a replaceable pump, coolant temperature sensors, a prescribed cooling-heat input, and two controllers. The stack is connected through from_stack and to_stack; pin_p and pin_n supply the pump electrically.

Working principle

The stack-temperature PI controller adjusts pump flow to track T_stack_set. A second proportional controller uses the reservoir temperature error to calculate the cooling heat-flow command. The reservoir starts at tank_fill_fraction of its specified height and at 323.15 K.

Tank dimensions, fill level, coolant medium, stack set point, and reservoir set point are configurable. Controller limits and tuning should be checked for the connected stack and coolant circuit.
