VirtualFCS.Thermal.PreHeater

Model Description and References

The PreHeater models an electrically heated fluid pipe. The electrical power dissipated by the internal resistor R1 is transferred to the pipe through a thermal conductor and heat capacity.

Implementation notes

The heater heat flow equals the resistor loss power, Q_flow = R_eq*I^2. The internal pipe start pressure is fixed at 102502 Pa, the thermal conductance at 1777 W/K, and the thermal capacity at 100 J/K. These values are implementation constants rather than user parameters.

Governing Equations

prescribedHeatFlow.Q_flow = R1.LossPower;
