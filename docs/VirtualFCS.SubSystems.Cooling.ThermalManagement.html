VirtualFCS.SubSystems.Cooling.ThermalManagement

Model Description and References

ThermalManagement is a compact cooling-loop example that transfers heat from a hot-water circuit to a separate coolant circuit.

Composition and operation

A heat exchanger connects the hot-water ports HotWaterIn/HotWaterOut to the coolant loop. The coolant loop contains a pump, temperature sensors, fixed-temperature source and sink boundaries, and a PI controller. The controller compares the cold-side temperature with a 328.15 K set point and commands the pump within a 0.2 to 0.5 flow range.

The hot-water and coolant media are replaceable. The 48 V source and boundary conditions are example values for system-level thermal-management studies.
