VirtualFCS.Electrical.BoostConverter

Model Description and References

A rigorous model for DC-DC boost converters. The two boolean inputs allow firing the gates separately.
Note that the rate of simulation is directly dependent on the PWM frequency, since at each change an event is triggered. In practice, this model can be used for detailed simulations in the sub-second range.
