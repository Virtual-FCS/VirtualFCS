VirtualFCS.Powertrains.RangeExtenderPowertrain_ECMS

Model Description and References

Fuel-cell/battery range-extender powertrain using equivalent-consumption minimization (ECMS). The controller selects the fuel-cell contribution from power demand, battery state of charge, and operating measurements, and sends a power request to FuelCellSystemController, which generates the DC-converter current reference. The controller receives battery voltage and current together with total power demand and fuel-cell operating measurements. The declared stack cell count is passed to the fuel-cell system and ECMS controller.
