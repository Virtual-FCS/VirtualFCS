VirtualFCS.Fluid.MixingVolume

A lumped fixed volume

Model Description and References

This class implements a fixed mixing volume with two non-directional flow ports and a conditional heat port.

The volume does not exchange work, but can exchange heat through the heatPort. The state of the internal holdup is described by the medium variable, whose properties are bound to the port pressure and outflow variables.

If the heatPort is inactive, the volume will be maintained at the constant temperature given by T; if heatPort is active, the temperature may vary, in particular adiabatically if nothing is connected to the heatPort.

Note that T is a parameter inherited by ConditionalHeatPort: when the heatPort is active, its value is arbitrary and inconsequential. The temperature of the fluid in the volume is always given by medium.T, not just T.

A pressure drop is implemented with linear hydraulic resistance R_flow. Note that the outlet flow is not guaranteed to be the same as the inlet, so the average value is used.
The medium is assumed to be represented by the average of inlet and outlet pressure.

Numerical stability note

Please note that low values of R_flow can have destabilising numerical effects and induce singularities.

Governing Equations

port_a.p - port_b.p = R_flow * (port_a.m_flow-port_b.m_flow)/2 "Pressure drop proportional to average mass flow";

medium.p = (port_a.p + port_b.p)/2;
