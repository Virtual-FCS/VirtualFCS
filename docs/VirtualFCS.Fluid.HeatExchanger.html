VirtualFCS.Fluid.HeatExchanger

Model Description and References

This is a discretised, 1-D heat exchanger. Detail level can be adjusted by setting the n parameter for the discretisation steps.
The class is implemented as two trains of MixingVolumes, one on each side, thermally connected one by one through a thermal conductance. Volumes and thermal conductances are assumed to be equally split between the MixingVolumes.

Volumes of both sides 1 and 2 can be set separately, but the default is for V_2 to be equal to V_1. The thermal conductance UA is given as a single number, as neither U nor A are used elsewhere.

The exchanger can be configured as cocurrent or countercurrent (default), which is implemented by swapping the train inlet and outlet of side 2.
Note that it is fully possible to obtain a cocurrent setup by inverting flow in one of the sides compared to the expected direction (port_a to port_b); this is discouraged as it can be confusing to users.

Governing Equations

T_1[n] = {conductors[i].port_a.T for i in 1:n};

T_2[n] = {conductors[i].port_b.T for i in 1:n};

DeltaT[n] = {conductors[i].dT for i in 1:n};

Q_flows[n] = {conductors[i].Q_flow for i in 1:n};

Q_flow = sum(Q_flows);

for i in 1:(n-1) loop connect(mixvols_1[i].port_b, mixvols_1[i+1].port_a);

connect(mixvols_2[i].port_b, mixvols_2[i+1].port_a);

end for;

connect(mixvols_1[1].port_a, port_a1);

connect(mixvols_1[n].port_b, port_b1);

if flow_c == Configuration.counterCurrent then connect(mixvols_2[1].port_a, port_b2);

connect(mixvols_2[n].port_b, port_a2);

else connect(mixvols_2[1].port_a, port_a2);

connect(mixvols_2[n].port_b, port_b2);

end if;

for i in 1:n loop connect(mixvols_1[i].heatPort, conductors[i].port_a);

connect(mixvols_2[i].heatPort, conductors[i].port_b);

end for;
