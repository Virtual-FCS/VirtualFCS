VirtualFCS.Control.FuelCellSystemController

Model Description and References

Converts requested fuel-cell power into a current reference by dividing by the measured stack voltage. The divisor is limited to at least 0.1 V, preventing a zero-voltage division. The resulting current reference drives the DC converter; this block does not impose an additional current limit.
