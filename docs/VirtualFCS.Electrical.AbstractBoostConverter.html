VirtualFCS.Electrical.AbstractBoostConverter

Model Description and References

This is a class representing a generic DC-DC architecture with coupled inductors.
The abstract commutators can be specialised to actual switches, allowing study at short time scales, or to averaged components allowing integration within fuel-cell system models.

Stability note

Consistently with specifications, this model does not have an input capacitor, but this may be necessary to numerically stabilise the model into which this unit is integrated.
