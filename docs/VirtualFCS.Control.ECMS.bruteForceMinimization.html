VirtualFCS.Control.ECMS.bruteForceMinimization

Model Description and References

Searches numIterations equally spaced fuel-cell power candidates between minFCPower and MaxFCPower. Battery power is powerDemand minus candidate fuel-cell power. A candidate is feasible only when batteryPowerMin < batteryPower < batteryPowerMax; the bounds are strict. The candidate with the lowest costFunction value is returned. numIterations must exceed one. If no feasible candidate improves the initial value, optimalParameter remains minFCPower and minimumValue remains infinity.
