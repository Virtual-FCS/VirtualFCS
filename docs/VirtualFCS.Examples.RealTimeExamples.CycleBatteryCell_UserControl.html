VirtualFCS.Examples.RealTimeExamples.CycleBatteryCell_UserControl

Example demonstrating real time user controlled galvanostatic operation of a Li-ion battery cell.

Model Description and References

This real-time example lets the user control Li-ion cell current with the keyboard up and down keys. The current is limited to -4.4 A to +4.4 A.

The cell starts at SOC = 0.01 and 298.15 K. It requires Modelica_DeviceDrivers for keyboard input and real-time scheduling.
