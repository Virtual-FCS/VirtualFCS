VirtualFCS.Electrochemical.Examples.PEMElectrolyserTest

Model Description and References

This is a simple test of a PEM electrolyser with variable current pushed through it while undergoing pressurisation.
Note that the sources and sinks are implemented with "hard" constraints rather than physical valves to simplify the example; it is easy to realise non-physical conditions if e.g. the pressure ramp is too fast (producing backflow into the stack).
