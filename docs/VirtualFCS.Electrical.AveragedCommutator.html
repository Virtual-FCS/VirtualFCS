VirtualFCS.Electrical.AveragedCommutator

Model Description and References

An averaged commutator for boost converters. The unit is implemented completely in code.
The equations state that, given an input duty ratio D:
  • The input voltage is (1-D) times the output voltage;
  • The sum of entering currents is zero;
  • The current exiting from the negative pin is D times the input positive pin;
  • No power dissipation occurs.

Governing Equations

p1.v - n.v = (1 - D)*(p2.v - n.v);

p1.i + p2.i + n.i = 0;

n.i = -D*p1.i;

LossPower = 0;
